# Descarga efectiva en el río Magdalena: informe del dashboard

Kevin Clemente Rosario y Manuel Meza Castro. Universidad del Norte.

Libro en línea: https://qclemente.github.io/Informe_Dashboard_Magdalena_ML/

Dashboard: https://dashboard-magdalena.onrender.com

Los notebooks se ejecutan en orden (`01_contexto`, `02_eda`, `03_modelos`) con las
dependencias de `requirements.txt`. El libro se compila con MyST y se publica con
`publicar.ps1`.

Datos: IDEAM, portal DHIME. La carpeta `datos` contiene únicamente la serie diaria
consolidada de caudal y los resultados agregados; los archivos originales no se
redistribuyen.
